# Le grand tirage de Noël 🎄

Petit site statique pour organiser le Secret Santa de Jade, Carla, Tristan, Eflamm, Samia, Meven et Camille.

## Mise en ligne

Dans le dépôt GitHub : ouvrez **Settings → Pages**, choisissez **Deploy from a branch**, sélectionnez la branche `main` et le dossier `/ (root)`, puis cliquez sur **Save**. GitHub publiera le site à l'adresse indiquée dans cette page (généralement `https://dnt29-ctrl.github.io/secret-santa/`). La première publication peut prendre quelques minutes.

## Utilisation

1. Ouvrez la page publiée dans votre navigateur.
2. Cliquez sur **Faire le tirage & préparer les liens**.
3. Envoyez à chacun·e son lien personnalisé en privé. Chaque lien ne révèle que le destinataire de cette personne.

Le tirage est sauvegardé dans le stockage local du navigateur qui l'a créé. Gardez donc le même navigateur pour retrouver les liens. Ne cliquez pas à nouveau sur le bouton sauf si vous souhaitez refaire le tirage : cela invalidera les liens précédents.

Les liens personnels chiffrent le nom de la personne et son destinataire dans le fragment de l'URL. Le fragment et la clé ne sont pas envoyés au serveur. Envoyez le lien complet en privé et évitez de publier la liste des liens.

## Règles

Personne ne se tire soi-même. Les couples Jade–Carla, Tristan–Eflamm et Samia–Meven ne se tirent pas l'un l'autre. Camille participe normalement. Chaque destinataire est attribué une seule fois.
